# T18 查询库：与 COmPOSER 的对照、值得学的、我们更好的、改进方向与落地架构（提案，待拍板）

依据：

  `optimizer_research/papers_2024_2026/reading/COmPOSER.md`。
- 我们的查询库：`docs/em/library.md`、`src/ic_opt/library/`（12 个文件，约 3500 行）、配方 `lib_design` / `lib_signoff`。
- 本次新量的数据：用户私有库（仓库外，6 张表：电感 2 张、变压器 4 张）里"按电学值能不能取到已有的行"的统计
  （第 5.1 节；只读缓存的数据集，没有跑仿真）。

说明用词：表 = 一个器件族在一种金属上的全部数据；行 = 一次真实 EMX 的结果（带 S 参数文件）；结果列 = 电感、Q、耦合系数、

## 1. 论文里与查询库对应的是哪一部分

COmPOSER 是从指标到版图的整条流程（LNA、PA，65 nm，到 60 GHz）。与查询库对应的只有它第 1 阶段里的"电磁优化器"：

| 项目 | 论文的做法（出处） |
| --- | --- |
| 数据 | 螺旋电感 8 万个几何（圈数、线宽、圈间距、内半径），Python 版图生成器 + EMX，称 24 小时（§3、表 4）。取值范围、扫频、网格、并行数未给 |
| 正向模型 | 随机森林（200 棵）：几何 → 电感 L、Q 峰值、Q 峰所在频率、自谐振频率 四个标量；MAPE 0.09% 到 0.35%（图 3）。训练 / 测试怎么分、是不是留出数据未给；没有报告模型失效的情形 |
| 逆向选几何 | 给目标电感，在电感相差 5% 以内的候选里取式 (1) 最大的：Q 峰、Q 峰频率、自谐振频率三项直接相加，减去电感偏差的平方（没有归一化或权重） |
| 多个等价解 | 数据集每个几何按引出端位置标成 1/4、1/2、3/4、1 圈四种；每种各给一个最好的，共 4 个解交给布局去挑（图 4、图 5） |
| 传输线与共面波导 | 一个近邻回归器直接由（特征阻抗、电长度）给出（长、宽、间距），不建正向模型；图 2 标注按面积最小取 |
| 按值换器件种类 | 目标电感小于 100 pH 用传输线，否则用螺旋电感（65 nm 的常数） |
| 进电路的方式 | 单向链：解析公式给出要多大的电感 → 逆向选几何并拿回它的自谐振频率 → 用式 (11) Z = 2πf₀L / tan(2πf₀ / 4f_SRF) 修正匹配电容。设计过程 0 次电磁仿真、0 次电路仿真 |
| 复核与不符时 | 整版图做一次 EMX + Spectre；不达标就收紧那条约束、从头再综合（收紧多少、最多几轮未给）；实验里 LNA 一次通过 |
| 范围 | 只有电感、传输线、共面波导；没有变压器；一个工艺一个金属叠层；没有 corner |

## 2. 逐项对照

| 方面 | COmPOSER | 我们的查询库 | 判断 |
| --- | --- | --- | --- |
| 器件种类 | 电感、传输线、共面波导 | 电感、五种变压器（含中心抽头的生成器）；没有传输线与共面波导 | 各有缺口 |
| 每张表的数据量 | 8 万 | 约 500 到 2400 行 | 我们省两个数量级 |
| 模型 | 随机森林，点预测 | 高斯过程（按圈数分层、对数目标），给区间；可由其它结果列组合（比值、谐振） | 我们更好 |
| 预测的可信度 | 一个总的 MAPE | 区间按留出残差校准到 95%；超出把握的答 `uncertain`；超出数据范围的答 `out_of_domain` 并给理由和最近的行；自谐振在扫频之外的答 `above_sweep` | 我们明显更好 |
| 结果列 | L、Q 峰、Q 峰频率、自谐振频率（与工作频率无关的 4 个标量） | 低频值、峰值、系统自谐振频率，以及**工作频率处**的 L、Q、k（清单里声明的频点） | 我们更贴近设计；但只能在声明的频点上答（论文任意频率都能用） |
| 逆向查询 | 电感 ±5% 内按式 (1) 取最大 | `lib.suggest`：每个结果列给窗口或"目标 ± 容差"，另给一个目标（最大化 / 最小化），按区间的保守一侧排序；已有的行先列；候选必须过数据范围检查、整段区间都在窗口内、真实生成器能画出来并过 DRC 审计 | 我们明显更好 |
| 多个解 | 每种引出端位置各一个 | 按几何距离拉开的 n 个；不按"种类"分组，不含占地与端口位置 | 论文这一点值得学 |
| 能回答"哪一片几何都行" | 无 | `lib.region`：满足全部窗口的区域、哪条窗口最紧、到没到库的边 | 我们独有 |
| 往哪里补数据 | 无（一次性 8 万） | `lib.densify` 按模型的不确定度挑下一批几何；`lib_signoff adopt=true` 把真实结果并回库 | 我们独有 |
| 预测对不对的复核 | 整版图一次 | `lib_signoff`：预测先记下，再跑 EMX，逐个结果列给 z 分数和是否落在区间里 | 我们更细 |
| 进电路优化 | 零仿真的单向链（电路一侧是 LNA / PA 专用公式） | 没有接上：电路联合优化（em_circuit 链）每个点都跑 EMX；`lib_design` 只优化单个器件 | **论文这一点最值得学** |
| 任意电路 | 只有写了公式的 LNA、PA | 任何 Spectre 测试平台 | 我们更通用 |
| 换工艺 | 未讨论，常数写死 | 工艺规则文件 + `em.validate_profile`，已在三个工艺上用过 | 我们更好 |
| 查询速度 | 称微秒级 | 没有量过；首次要拟合模型（组合模型一张表约 30 分钟），之后有磁盘缓存 | 论文快；对我们够不够用取决于方向 1 |

## 3. 值得学的（按价值排）

1. **把库接进电路设计，设计过程里不再跑电磁仿真。** 这是论文的主要贡献在查询库一侧的体现，也是我们最大的缺口
   （待办 N-85）。它用的是"电路要一个电学值，库给一个几何并把这个几何真实的 Q、自谐振频率还回去"这条链。
2. **在任意工作频率上作答。** 论文的四个标量与频率无关，20 到 60 GHz 共用。我们的 L、Q、k 只在清单声明的频点上有
   （私有库是 10 / 28 / 40 / 60 GHz），设计在 33 GHz 就问不了。我们每一行都存着完整的 S 参数，缺的只是"临时加一个频点"
   的做法。
3. **同一个电学值给出几个"种类不同"的解，让后面的环节挑。** 论文按引出端位置分四种各给一个。对我们：按圈数、按表
   （器件族 × 金属）、按端口朝向各给一个最好的，而不只是几何上拉开的 n 个。
4. **答案里带占地。** 论文的传输线按面积最小取，电感的多个解是为了布局。我们的答案只有几何变量和电学值，没有外框
   尺寸、面积、端口位置；逆向查询也不能把面积当目标或窗口。
5. **跨种类选器件。** 论文按电感值在传输线与螺旋电感之间选。我们的逆向查询要先指定一张表；"这个电感值用哪个族、哪层
   金属最好"要用户自己逐表问。
6. **复核不过时的固定做法。** 收紧没达标的那条约束再综合一次。我们有复核（`signoff`、`lib_signoff`），没有"不过之后
   怎么办"的配方。

## 4. 我们明显更好的（都有已记录的数字）

1. **知道自己什么时候不可信。** 区间校准后真实复核覆盖 94.6% 到 98%；超范围、把握不足、自谐振在扫频外三种情况分别
   作答。论文的随机森林在数据之外只会给出最近的叶子的值，没有任何提示；它的精度数字没有说明是不是留出数据。
2. **数据量小两个数量级而精度相当。** 我们电感表留出中位误差 0.03% 到 0.23%（论文 MAPE 0.09% 到 0.35%），用的是
   约 500 行而不是 8 万行。
3. **有变压器。** 五个族、耦合系数、系统自谐振频率（次级谐振反射到初级的情形专门处理过）。论文没有变压器。
4. **给的是工作频率处的值。** 论文给 Q 峰值；工作频率离 Q 峰远时，用 Q 峰估损耗会偏。
5. **候选一定画得出来。** 每个候选都经真实生成器和 DRC 审计；已有的行直接带真实 S 参数。
6. **库会长。** 按不确定度挑点、真实仿真、并回库、模型按内容重新拟合，是闭合的一圈；论文是一次性数据。
7. **逆向查询的目标写得清楚。** 窗口是硬条件，目标按区间保守一侧排；论文式 (1) 把 Q（几十）和频率（几十到上百）
   不加权相加。
8. **电路一侧不限拓扑。** 任何导出的测试平台都能优化；论文每种电路要手写一套公式。

## 5. 改进方向

### 5.1 方向 1（核心）：库里的器件直接进电路优化，设计过程零 EMX

做法：电路优化时，电磁器件不再"每个点画版图 + EMX"，而是从库里取一**已有的行**，把这一行真实的 S 参数绑进网表去跑
Spectre。观测和新做一次 EMX 一样真实，不花 EMX 预算。策略面对的是器件的电学值（电感、耦合系数），不是几何。

能不能取到行，用私有库量了一下（只读，工作频率处的结果列，自谐振余量已计入）：

| 表 | 可用行 | 电学值 | 结果 |
| --- | --- | --- | --- |
| 电感（2 张） | 203、215 | 电感 ±3% 分档，63 档 | 61、62 档有行，35、39 档有 3 行以上；同一档里最好的 Q 比中位数高 6% 到 7% |
| 变压器（4 张） | 1290 到 1474 | 只看初级电感 ±3% 分档 | 每档都有行，中位 31 到 40 行；同一档里最好的 Q 比中位数高 18% 到 21% |
| 变压器 | 同上 | 初级电感、次级电感各 ±3%，耦合系数 ±0.05 | 一行附近还有别的行的只占 34% 到 42%；在取值范围里随机给一个目标，能取到行的只有 12% 到 15%（±5% 时 25% 到 31%） |

读法：电感只有一个电学值，现有的行够用；变压器有三个电学值，"给一个目标、在容差里找行"多数时候找不到。所以变压器不能
照搬论文"目标 ± 容差"的做法，三个候选方案：

| 方案 | 内容 | 好处 | 代价 |
| --- | --- | --- | --- |
| A1 目标加容差 | spec 里器件变量是电学值的网格；每个点在容差内取 Q 最高的行；取不到就算这个点没有器件 | 最接近论文；实现最小 | 变压器多数点取不到行；策略要学"哪里有行" |
| A2 行就是候选（推荐） | 器件的候选集合就是库里的行；每一行用它自己的电学值当坐标（取到变量的网格上）；策略照常在电学值空间里选点，选出的点落到最近的一行 | 每个候选都是真实的行，不会取不到；同一行不会被重复仿真；电感和变压器一个做法 | 策略要支持"候选只能取自一张允许的组合表"（对所有策略是同一处改动：提点后就近落到表上） |
| A3 几何变量，落到最近的行 | spec 照旧写几何变量，评估时落到几何上最近的行 | spec 不用改 | 几何 5 到 7 维，比电学值 1 到 3 维难学；几何相近不代表电学值相近 |

行不够密的地方，用已有的一圈补：`lib.suggest` 按电学值窗口给出预测的几何 → `lib_signoff adopt=true` 真实仿真并入库
（EMX 要批准）→ 这些行成为新的候选。这样 EMX 只花在设计真正去到的区域，并且留在库里给以后的设计用。

一个前提：用户的 MixerCS 平台用的是**带双中心抽头**的变压器（6 端口生成器绑到 10 端的实例），私有库的 4 张变压器表
都**不带抽头**（4 端口），绑不进那个实例。方向 1 在这个平台上落地之前要先建带抽头的表（真实 EMX，需批准）；或者先在
不带抽头的电路上验证。

### 5.2 方向 2：任意频率作答

问 `Lp@33`、`Qp@33` 时，如果 33 GHz 不在清单里，库从每一行存着的 S 参数里临时算出这一列（不跑 EMX），拟合并缓存模型，
和声明过的频点一样作答。方向 1 需要它（电路的工作频率通常不在清单的频点上）。已有行的这一列是直接算出来的真实值，
不经过模型。

### 5.3 方向 3：跨表查询、每种各给一个、答案带占地

- `lib.suggest` 可以一次问几张表（或全部），每张表各答，再合并排序，答案标明来自哪张表。
- 新增"按某个离散项分组、每组给最好的一个"（圈数、表）。
- 每个候选和每一行带外框尺寸与面积（由生成器算出，不仿真）；面积可以当目标（`objective=min:area`）或窗口。
- 端口位置：先只在答案里给出端口坐标与朝向；要不要把"端口朝向"做成生成器的可选项是版图生成器一侧的事，另议。

### 5.4 方向 4：复核不过时的配方

带库器件的电路优化结束后：最好的几个点在完整 corner 上复核（`signoff`，已有）。若选中的行是后补的预测几何，器件已经
真实仿真过；没有"模型与真实不符"这一步。不达标时按论文的做法收紧那条约束（收紧量 = 差多少）再优化一轮，限定轮数。
这是一个薄配方，不改数值核心。

### 5.5 方向 5：传输线与共面波导两个族（看需要）

论文覆盖而我们没有。需要新的生成器、新的结果列（特征阻抗、电长度、每毫米损耗）和新表，工作量在版图生成器与测量口径，
不在查询库。用户的电路目前用的是变压器，建议等有真实需要再做。

### 5.6 不学的

- 8 万行加随机森林：我们的做法数据省得多，而且要的是区间。
- 式 (1) 的打分：量纲不同的项直接相加。
- 论文的第 2、3 阶段（布局、布线、电源网）：不在查询库的范围。
- 用公式代替电路仿真：只对写了公式的拓扑成立。

## 6. 落地的架构

原则不变：观测只认真实仿真；EMX 要用户批准并给资源；每个部件只做一件事；策略、调度、判定不为电磁特殊处理。

```text
                 库根目录（仓库外）                         电路工程
        ┌──────────────────────────────┐          ┌─────────────────────────────┐
        │ 表：行（几何、S 参数文件）     │          │ spec.yaml                    │
        │ library.yaml                 │          │  devices: xfmr 来自库（哪些表、│
        └──────────────┬───────────────┘          │   工作频率、自谐振余量、取行规则）│
                       │                          │  variables: 电路变量 + 器件的   │
          ① 数据集（已有）＋ 临时频点（新）          │   电学值（电感、耦合系数）       │
                       │                          └──────────────┬──────────────┘
          ② 电学索引（新）：每行 = 电学值 + 占地 + S 参数路径        │
                       │                                         │
                       ├──── lib.pick（新块）：电学值 → 行 ───────┤
                       │                                         ▼
          ③ 候选表（新）：器件允许取的组合 ──► 策略提点后就近落到表上（策略本身不变）
                                                                 │
                                                                 ▼
             评估流水线：取行（新，点级，不仿真）→ 绑 S 参数（已有）→ Spectre → 取指标 → 判定（都已有）
                                                                 │
                                                                 ▼
             观测：电路指标 + 器件指标（这一行的真实值）+ 取的是哪张表哪一行
                                                                 │
             行不够密 ──► lib.suggest（电学值窗口）──► lib_signoff adopt（EMX，需批准）──► 回到 ①
```

| 部件 | 新增 / 改动 | 说明 |
| --- | --- | --- |
| `library/dataset.py` | 改：结果列可以是"任意频点" | 按需从 S 参数算一列并按内容缓存；清单声明的频点不变 |
| `library/index.py` | 新 | 由一张或几张表在一个工作频率上建"电学索引"：每行的电学值、占地、S 参数路径；按内容缓存 |
| `blocks`：`lib.pick` | 新 | 电学值（加取行规则）→ 行；`lib.suggest` 加多表、分组、面积 |
| `spec.py` | 改：器件可以声明"来自库" | 哪些表、工作频率、自谐振余量、取行规则；器件的变量是电学值；指纹含库的数据内容键（与 `Predict` 同样的做法） |
| `space.py` | 改：候选表 | 一个器件的变量组合只能取自一张表；提点后就近落到表上；对所有策略是同一处 |
| `stages`：取行 | 新（点级） | 代替"画版图 + EMX"两级；输出与 EMX 那一级相同（每个器件的 S 参数），后面的绑定、Spectre、取指标都不变 |
| 策略 | 不改 | `auto` 对"器件全部来自库"的 spec 选 `metric_gp`（现在 `metric_gp` 对带 EM 器件的 spec 一律拒绝） |
| 调度 | 不改 | 器件的约束（自谐振等）在取行时就知道，排在最前，不过就不跑电路仿真（待办 N-63 自然满足） |
| 配方 | 新：薄配方 | 带库器件的电路优化 → 复核 → 不过则收紧再来（5.4）；补行走已有的 `lib_signoff` |
| 摘要 / 报告 | 改 | 写出每个点取的行、最好点的几何与占地、哪些电学值区域没有行 |

分期（每期先写规格，测试用假仿真器；需要真实仿真的单独请示）：

| 期 | 内容 | 真实仿真 | 验收 |
| --- | --- | --- | --- |
| L1 | 任意频点；电学索引；`lib.pick`；`lib.suggest` 多表、分组、面积与占地 | 无 | 留出检验：把一行拿掉，按它的电学值取行，取到的行的 Q 与它相比；已有 G 门（精度、覆盖）不退步 |
