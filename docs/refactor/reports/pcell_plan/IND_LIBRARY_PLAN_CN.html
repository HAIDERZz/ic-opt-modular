电感建库提案

六族里先做 ind_sym。这一页给三件事：参数化建模的取值范围（连同为什么这样取、覆盖到什么感值）、EMX 仿真设置，以及已经跑完的先导批——它定下了网格分辨率并量出了 full-wave 的真实代价。你批准后开跑正式批。

0建库基本原则（本轮起生效）

  • 不带中心抽头。整个建库不打 CT：抽头对感值影响很小，而它会把每个器件的参数空间乘上一个与查询目标无关的维度。查询库的目标量是 L、k、SRF（外加 Q）。
  • 线宽必须覆盖 4–10 µm。每一族、每一种体材都要在这个区间上取满，不能因为某个 OD 只造得出窄线就把宽线漏掉。
  • xfm_bs / xfm_ms 两绕组外径比限制在 0.5×–2× 之间。超出这个比例的两级不再是耦合器件，进库没有意义（本页只做电感，这条在做到那两族时执行）。
  • 抽样必须"像真器件"。随机抽样只保证参数在范围内，不保证器件有意义；每一族都要有一条明确的物理合理性规则把无意义点滤掉。电感这条规则是内径 ≥ 30 µm（见 §1）。
  • 一族一族来。每族先报参数范围 + EMX 设置 → 你批准 → 先导批测网格收敛与代价 → 你批准 → 正式跑。

感值覆盖 0.07 – 8.5 nH，四个十进程区间的点数分别是：<0.3 nH 88 个、0.3–1 nH 260 个、1–3 nH 436 个、3–10 nH 254 个。填充因子（1 − 内径/OD）落在 0.03–0.75，中位 0.32。

L 的估算用 Mohan 电流片公式（八边形系数），并用旧库 1899 行实测 Lp 标定：实测/公式的中位比值 0.835，标定后 |误差| 中位 2.3%、p90 5.1%。也就是说上表的 L 范围是可信的，真正的 L 以 EMX 结果为准。

一个需要你决定的取舍：150 GHz 封顶会让大部分单匝电感测不到 SRF。按旧库实测，NT=1 的 480 行里只有 41% 的 SRF 落在 150 GHz 以内（其余在 150–200 GHz 或更高）；NT ≥ 2 是 99–100%。L 与 Q 不受影响，只有 SRF 这一项会在 112 个单匝点上返回"带内无谐振"。

三个选项：① 就这样（单匝器件本来也是拿来当高频小电感用的，SRF 不是它的限制）；② 只把 NT=1 的 112 个点扫到 250 GHz（多 100 个频点 × 112 点，代价约整库的 +7%）；③ 全库扫到 200 GHz（代价 +33%）。我建议 ②：SRF 是你明确要查的量，而补的代价很小。

3EMX 设置

emx --full-wave --format=touchstone --s-impedance=50 --s-file=<dev>.s2p \
    --sweep --sweep-stepsize=1000000000 \
    --thickness=<T> --max-splits=<K> --edge-width=<E> \
    --via-separation=0.5 --include-command-line --verbose=2 \
    --log-file=emx.log --parallel=8 --simultaneous-frequencies=0 --max-memory=48G \
    --3d=AP,M10            # M10 体材时为 --3d=M10,M9
    -p p01=P1:G01 -p p02=N1:G02 \
    <dev>.gds <dev> /…/tsmcN28_1p10m.proc 150000000000
开关取值理由
--full-wave启用（旧库是 --quasistatic）两条依据：(a) 我们画了 M1 地环并给每个端口配了自己的地桩（p01=P1:G01），端口有确定的回流路径，full-wave 的端口定义是良态的——这正是你说的"留了 GND pin 所以可以用 full wave"；(b) 150 GHz 在 SiO₂ 里的波长约 1 mm，最大器件（OD 240 µm + 地环，对角 ≈ 400 µm）已经是 λ/2.5，推迟效应与辐射损耗不能再忽略，准静态会低估损耗并把 SRF 算高。
--sweep --sweep-stepsize=1e9，末位 150e90 → 150 GHz，步进 1 GHz，151 个频点你定的。起点 0 Hz 让低频段 L 的取值（L_lf 取 ≤3 GHz 的有限值均值）稳定。
--3d=AP 体：AP,M10；M10 体：M10,M9把绕组金属与跨线金属按真实厚度建三维（有厚度的导体才有正确的趋肤/邻近效应）。其余层（含 M1 地环）仍按零厚度面处理：M1 很薄，三维化它会让网格翻倍而收益存疑——先导批里会量一下这个差。
--thickness / --edge-width / --max-splits先导批定（候选：0.5/0.5/3 = 旧库；0.3/0.3/4；0.25/0.2/5）这是你说的"精度要够高"的落点。150 GHz 下铜的趋肤深度约 0.17 µm，而旧库用的 0.5 µm 边缘网格 ≈ 3δ，明显偏粗；但直接跳到最细会让网格与代价失控。做法是先导批测收敛，用"最粗但与最细一致"的那一档跑正式库（判据见 §4）。
--via-separation=0.5沿用把 0.5 µm 内的过孔合并成一块，跨线过孔阵列的网格量降一个量级，对集总参数无影响。
--simultaneous-frequencies=0硬性保留2026-07-09 服务器被单个 EMX 压死的直接原因就是并发频点求解；0 = 逐频点求解，内存有界。这条不因为任何提速需求放开。
--parallel / --max-memory先导批 8 线程 / 48 GB；正式批按实测定并发旧库是 4 线程/32 GB 上限、实测峰值 0.83 GB。full-wave 的真实占用未知，先导批量完再定并发（总量守 ≤128 线程 / ≤256 GB）。
-p p01=P1:G01 -p p02=N1:G02沿用每个信号端口对自己的本地地桩。sNp 的列序由端口名的字典序决定，p01/p02 的零填充保证列序 = P1, N1。
--mode不用差模量（Lp/Qp/SRF）由我们自己的 measure 内核从完整 S 矩阵做理想巴伦变换得到，已与 OCEAN 对齐到 4.7e-6；让 EMX 直接出差模会丢掉单端信息，且无法再复核。
timeout_s7200（旧 3600）full-wave 单点可能远慢于准静态，超时要给足，否则一个慢点会被误判成失败。

4′先导批结果（2026-09-23 已跑，21 次 EMX，全部成功）

  • 网格选"细"档：--thickness=0.25 --edge-width=0.2 --max-splits=5。它对极细档（0.15/0.1/6）的偏差：L ≤ 0.4%、Q ≤ 2.0%、SRF ≤ 0.1%，满足判据；中档对小电感的 Q 偏高 12.6%，粗档（旧库档）偏高 27%。
  • 旧库的网格对高频 Q 不收敛。小电感（单匝 60 µm）的 Q 峰落在 150 GHz 带边，由趋肤电阻主导；Q 随网格变细一路下降 24.4 → 21.6 → 19.5 → 19.2。L 和 SRF 在所有网格下都稳定（≤0.6% / ≤0.1%），所以旧库的 L/SRF 是可信的，高频 Q 偏乐观。
  • full-wave 与准静态在这个尺寸/频段内几乎相同（细网格下 L ≤0.04%、Q ≤0.6%、SRF ≤0.03%），full-wave 贵 2–5 倍。按你的要求仍用 full-wave：正式库总时长约 3 小时，代价可以接受，且消除了"150 GHz 下准静态是否成立"这个假设。
  • 地环三维化不需要：大电感上 --3d=AP,M10,M1 与不含 M1 相比 L +0.00%、Q_peak -0.01%，网格却多 10%。

6需要你确认

D1 · 参数网格 （待确认）

建议：照 §1 跑 1038 个点（2 体材 × OD 8 × W 7 × S 3/1 × NT 5，内径 ≥ 30 µm）。先导批的三个几何都落在网格的角点与中心，EMX 实测 L 与估算差 −3% / +4% / −2%，网格的感值覆盖（0.07–8.5 nH）可信。

D2 · 150 GHz 封顶下的单匝 SRF （待确认）

建议：主扫 0–150 GHz；NT=1 的 112 个点单独扫到 250 GHz 补齐 SRF（≈10 分钟）。先导批的小电感在 150 GHz 内没有谐振，印证了这个问题确实存在。
或：接受单匝"带内无谐振"（SRF 记为空）。

D3 · 网格分辨率 （已由先导批定）

细档 --thickness=0.25 --edge-width=0.2 --max-splits=5：对极细档 L ≤0.4%、Q ≤2.0%、SRF ≤0.1%。

D4 · 地环三维化 （已由先导批定）

不做：影响 <0.1%，网格多 10%。

D5 · 批准正式批

建议：按 §5 开跑：1038（+112）点，full-wave 细网格，8 并发 × 8 线程，约 3.3 小时。
备选：若你更在意速度，准静态在同网格下与 full-wave 差 <1%，总时长可降到约 1 小时。按你的要求我默认 full-wave。
