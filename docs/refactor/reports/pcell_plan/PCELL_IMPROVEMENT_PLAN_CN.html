0结论

  • "库会误导"成立，且可量化。库内 9,722 条 ok 行全部来自第 2–5 代几何（geom 2：3,758 / 3：2,242 / 4：300 / 5：3,422），当前代码是第 6 代，库中第 6 代行数为 0。抽样回放 480 个记录点：24% 用现行代码已复现不出相同几何，2% 现行代码直接拒绝；xfm_ms 两层分别 55% 与 73% 不同。
  • gdsfactory 值得学的是外围设施，不是几何算法。黄金几何回归、端口元数据随文件自描述、DRC 结果带坐标叠图、参数词汇统一——这四样值得抄。它的 RF 器件（_geometry.py）同样是手算多边形；symmetric_inductor 等三个组件因 __all__ 漏写在公共 API 和其自身 CI 中不可见。不引入 gdsfactory 依赖，只借方法。
  • 我方脚本最深的病根只有一个：同一几何量由多条独立表达式各自取整（八边形倒角公式在 _pcell_primitives.py 内复制 ≥ 5 处）。今日新实证：demo_6m 上 W=5.0/S=2.0 的 ind_sym，生成器放行、打包审计拒绝——画出来的对角段宽 5.006 µm、对角间距 1.994 µm（名义 5.0 / 2.0）。D5/D8/D9 与此同源。
  • 计划分 5 个里程碑：M0 安全网 → M1 原语收敛（根因修复，几何换代到第 7 代）→ M2 接口收紧 → M3 选做能力 → M4 重建库（真实 EMX，分批审批）。M0–M2 约 20 个提交；M4 需要 T10 的最小子集（em_sweep）先落地。
  • 需要你拍板 6 项（§8）：范围、取整策略、破坏性重命名、多开口环原语是否现在做、重建覆盖面与 sNp 复用、旧代数据处置。

4我方脚本的真实弱点

编号沿用两份报告；D 编号来自 2026-09-21 的 gdsfactory 对比审查。每条都给出代码位置，便于批准后逐条对账。

F1 · 一种环、一套硬编码倒角、公式复制 ≥ 5 处

全库唯一的环原语 base_oct_quad（_pcell_primitives.py:229-307）硬编码 8 边、45° 倒角（C = ceiltogrid(W·tan(π/8)+0.005)、A = roundtogrid(OD/(2+√2))），同一公式在 base_oct_quad_vias、base_xfm_half、base_ind_hud_cross（两处）、chamfer_staircase_delta（_pcell_core.py:1074）各抄一遍。它只支持"每象限一个开口"，于是 xfm_tw / xfm_il 只能从零重写八边形——960 / 1,448 行，对比复用内核的 ms / bs 207 / 232 行，4–6 倍的成本差直接来自原语层的不灵活。

F2 · 生成器所信 ≠ 审计所见（今日新实证）

demo_6m（公开规则：M5/M6 上 W>5.0 µm 且平行长度>20 µm 时间距 ≥ 2.0 µm）上扫 ind_sym OD∈{60…120} × NT∈{3,4,5} × W∈{3…6} × S∈{2,3}，共 144 个配置：52 个被生成器 fail-closed 拒绝，92 个放行；放行的 92 个里 9 个被打包审计 audit_gds 判违规，全部是 W=5.0 / S=2.0 的组合。原因：生成器按名义 W=5.0 判定"宽线规则不适用"（_effective_min_spacing，_pcell_core.py:1040，严格 >），但量化倒角把对角段画成 5.006 µm 宽、相邻环对角间距 1.994 µm（实测：16 条对角段 5.006、5 条 5.000）。审计看到的是画出来的 5.006 > 5.0，规则生效，1.994 < 2.0，违规。流水线里 Pcell 阶段会把这些点判 failed:pcell（不静默），但它说明：名义参数落在规则阈值上的几何，我们的生成器自己不知道它画了什么。这与 D5（地环跳变）、D8（44.9959°）、D9（center_spacing 无网格校验）是同一个根：多条独立取整链。

复现：docs/refactor/reports/pcell_plan/d4_probe.py（网格扫描 + 审计，结果 d4_probe.json）、wps_locate.py（边对坐标，wps/pairs.json）。

F3 · D5 / D9：中心偏移与地夹具各自取整

center_spacing_um（generator_plugin.py:322/397/474）只有 ge=0，没有 multiple_of（同一批类里 straight_extension_um 有 multiple_of=0.01）；CENTER_SPACING/2 直接进入后续所有坐标。地夹具 add_ground_fixture（_pcell_core.py:869-972）按端口到包围盒四边的欧氏距离启发式分边，再取"端口+stub_length"与"本体+inner_margin"两个下界之远者——两条独立取整路径差 1 nm 就会让内沿在两种判据间跳变，这就是审查记录的 151 行地环翻转。

F4 · D11：TW / IL 没有同网自短路守卫 确认开放

_check_ind_winding_segments（_pcell_guards.py:142-169）与紧凑候选的 holes() 环路检查只被 ind_sym 调用；tw（_pcell_xfm_tw.py:950）与 il（_pcell_xfm_il.py:1413）只有跨网的 _xfm_net_short。一个绕组因挤压/取整并成比匝数更少的连通分量时，两族都不会拒绝。

5向 gdsfactory 学什么、不学什么

学（借方法，不引依赖）

  • 黄金几何回归自动化（get_cells + difftest，逐层 XOR/IoU 而非字节）。我们已有显式 registry.py，比 gdsfactory 的 star-import 更不易漏——遍历注册表 → 默认配置 → 与入仓 GDS 物理比较。→ M0.2
  • 端口元数据随文件自描述（cross-section/port 信息内嵌 GDS/OASIS 元数据）。→ M2.1：结构化 ports 进 manifest。
  • DRC 结果与版图叠加（show(lyrdb=) / plot(markers=)）。→ M0.4：审计带坐标 + 渲染。
  • 统一参数词汇（d_out / N / width / spacing / center_tap / port_spacing 跨组件一致）。→ M2.2
  • 生成即校验（via_stack.py:250-258 摆完立刻反算 enclosure 不够就 raise）。我们已有；把宽线规则也纳入。→ M1.2
  • settings / info 两条通道（签名参数 vs 派生量）。对应 manifest 的 config / derived，T10 的 devices[].derived 已按此设计。

不学（及理由）

  • Path / CrossSection 画八边形环：gdsfactory 自己的 RF 作者在同类结构上也退回手算多边形（_geometry.py）。
  • 引入 gdsfactory / kfactory / Pdk / LayerStack 依赖：几十万行光子学框架，RF 覆盖薄、命名空间有已验证缺陷；我们要的四样都能在 klayout.db 上以小代价复刻。
  • 扁平命名空间 + 手工 __all__：正是 symmetric_inductor 不可见的根源。
  • 自动长哈希 cell 名：靠 64 字符截断 + $1 去重兜底，不可读；write_gds 已强制 topcell == 文件名。
  • to_3d() / get_klayout_3d_script()：只是可视化挤出，无材料/网格，不是 EMX 前处理。
  • round_corners / minkowski_sum、可变边数、微带闭式公式库：gdsfactory 的 RF 器件也没用；没有 EM 收益证据前不立项。

6改进计划

每项一个提交；换代 = 至少一条现有配置的 GDS 物理改变，需要新几何代；几何不变 = 黄金集与库回放必须逐点物理相等。顺序不可调换：M0 是 M1 的度量工具，M1 的根因修复决定 M4 的重建面。

7重建库（M4）

前置：T10.1（Pcell.identity = GEOMETRY_VERSION，M0.1 已含）+ T10.4 的最小子集 em_sweep（把 em-opt 的 12 份扫参计划 yaml 转成 ic-opt 点集 → evaluate）+ IC_OPT_LIBRARY 目录（T10 决策 1）。不需要 T10 的代理模型部分。

  1. 干跑（无 EMX）。12 层全部坐标（9,722 ok + 3,045 rejected = 12,767）经第 7 代生成器重建 → 表：物理相等 / 不同 / 新拒绝 / 新可造，每层附差异样图（M0.4）→ 你审阅。
  2. 仿真集（决策 D5）。默认 = 全部可造点重跑 EMX。备选 = 只重跑物理不同的点，物理相等者复用记录 sNp（前提：EMX 设置哈希一致，库内只有 4 组）。注意 M1.1 若采纳 D2 的推荐策略，几乎所有环的对角段都会变 ≤ 6 nm，"物理相等"率会接近 0——两个决策是耦合的。
  3. 成本。6k 扩库实测 2,242 点 / 3.5 h（≈ 5.6 s/点墙钟，含 pcell + 传输 + measure）；~10k 可造点 ≈ 16 h 墙钟。按批（如每批 1,000 点）--plan → 批准 → 运行；每批 ≤ 128 线程 / ≤ 128 GB（例如 8 路并发 × 8 线程 × 16 GB）。EMX 逐次噪声 |ΔS| ≤ 9e-5，重跑后对物理相等行做一次对照可作为回归证据。
  4. 结果。新库只含第 7 代行（决策 D6）；em-opt 的 sqlite 与 sweep 目录原地保留（你已裁定不动 em-opt）；GP 基准（T10 V6）在新库上复算。
真实 EMX 的每一批都单独 --plan 再批准；本页批准的是计划，不是任何一次仿真。

A.3 术语

  • 几何代（geom_version）：一次会改变至少一条现有配置输出 GDS 的代码改动之后的库标签；em-opt 里由 ingest.CURRENT_GEOM_VERSION 记账，ic-opt-modular 将由 GEOMETRY_VERSION 进 pipeline fingerprint（M0.1）。
