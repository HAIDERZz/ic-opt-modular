单圈变压器 Q 列加无量纲坐标的验收：没有采用

问题（BACKLOG N-19）：Qp@40 / Qs@40 在中心偏移 8–24 µm 一带误差 10–30%，B-12 与 N-17 两轮补点都没改善。方案 1：只给 Qp、Qs 曲线列加 feature_map: xfm_bs_dimensionless（Lp / Ls / k 已经用它），不改代码。验收在库的临时副本上做（xfm_bs_q_map_acceptance.py， 12 个进程 × 2 线程，1448 秒）：每张表 20 个外径档整档留出（80 折）；用今天的完整库（含 B-12、N-17 回流行） 预测测过但从未回流的设计（ap：N-17 与 B-12 各 10 个，m10：N-17 的 8 个可用点）；完整库校准。

结论

对 N-19 要解决的那一带，换坐标没有帮助，反而让区间变得过于自信，所以没有采用。N-17 偏移带的 10 个点上（xfm_bs_ap）：Qp@40 中位误差 11.9% → 13.3%，区间覆盖 90% → 40%；Qs@40 8.6% → 11.5%，覆盖 90% → 60%。逐点看，误差只是换了符号（+18% → −26%、+31% → −26%），幅度没降。m10 表的 8 个点：Qp@40 中位 5.5% → 4.2%，但覆盖 100% → 75%。原因：在无量纲坐标里这些点看起来离已有行很近，模型因此很有把握，而 Q 在谐振附近还依赖绝对尺寸（经 SRF），这些坐标没把它表达出来——"更自信但不更准"，正是查询库最不该有的行为。
换坐标对档与档之间的插值很有效，留作以后。整档留出的 p90 误差从 30–45% 降到 6–19%（例如 ap 的 Qp@40 留出 OD_P 档 44.8% → 8.9%，Qs@40 43.9% → 6.6%）。这说明 Q 列在原始坐标下确实难插值；等偏移带补足行（或换成 Q 峰值 × 比值的建法）后，再连同坐标一起改，用同一套脚本验收。
下一步的两条路。方案 2：Q@f = Q 峰值（Qp_peak，平滑量）× 单独建模的比值，需要改 manifest 校验与组合模型（约半天），再验收。方案 3：在没吃透的角落（外径比 1.1–1.25 × 线宽 8–10 µm × 偏移 15–20 µm）定向补 20–30 点真实 EMX（约 15 分钟，需批准），因为两轮补点各只落了 3 / 2 个点在那里。两条路可以并行。
